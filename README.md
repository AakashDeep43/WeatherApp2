# 🌦️ WeatherApp2

A simple weather web application using Flask for backend and vanilla HTML/CSS/JavaScript for frontend. It fetches live weather data based on the user's input and displays temperature, humidity, and other details.

## 🔧 Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python (Flask)
- **API:** OpenWeatherMap API

## 🚀 How to Run
### Backend
```bash
cd backend
pip install -r requirements.txt
python app.py
